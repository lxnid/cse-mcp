# Changelog

All notable changes are listed here. Versions follow [Semantic Versioning](https://semver.org).

## [0.1.0] - 2026-11-10

First public release.

- 10 read-only tools: market overview, top movers, stock search, stock profile, price history, trades by price, sector indices, index history, daily market summary, announcements.
- Install options: Claude Desktop extension (`.mcpb`), PyPI (`uvx cse-mcp`), Claude Code plugin, MCP Registry.
- Optional Streamable HTTP mode (`cse-mcp --http`).
